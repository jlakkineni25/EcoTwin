# EcoTwin

Wind-aware PM2.5 forecasting for 37 Delhi CPCB monitoring stations, with a digital-twin dashboard.
Final year project, Team 86, Amrita Vishwa Vidyapeetham (23CSE498).

The current code, notebooks and dashboard are in [`v2_clean/`](v2_clean/). Start with `v2_clean/CLAUDE.md`
and `v2_clean/TASKS.md` for the project context and status. The cleaned dataset is on Zenodo:
https://doi.org/10.5281/zenodo.23619409

## Use of AI assistance

Parts of the code, notebooks and documentation in this repository were developed with the help of an AI
assistant (Anthropic's Claude, used through Claude Code). The team directed the work, ran the experiments
and reviewed the results. Earlier commit messages in this repository carried a co-author line for the assistant;
those lines were removed from the commit messages in October 2026, and this note replaces them. The
experiments, results and conclusions reported in the project are the team's own to verify and defend.
